# AI 助手

需要自动执行命令并按结果继续排查时，切换到[运维 Agent](OPS_AGENT.md)。以下说明默认的对话模式。

右侧 AI 助手用于解释终端问题、整理排查步骤和提供命令建议。点击工具栏的 AI 按钮可以打开或关闭面板；终端和分屏会为面板让出空间。

## 连接模型服务

在助手设置中填写自己的服务地址、模型名称和 API Key。服务需要提供 OpenAI 兼容的 **Chat Completions** 接口；可以使用自托管服务。

- **Endpoint**：模型服务的 HTTP 或 HTTPS Base URL，也可填写完整的 `/chat/completions` 地址。例如 `http://127.0.0.1:11434/v1`。地址原样保存在本机，由后端补齐请求路径。
- **Model**：服务实际提供的模型名称。
- **API Key**：按服务要求填写。不要求鉴权的自托管服务可留空。

保存后，服务地址、模型名称、面板宽度和上下文偏好保存在本机。默认勾选“保存密钥到应用本地加密库”：应用使用 AES-256-GCM 加密保存 Key，并用本机安装生成的随机解密材料自动解锁，无需系统凭据库或主密码。不同服务隔离保存，聊天与 Embedding 使用不同命名空间。取消勾选并保存后，移除该服务的应用本地已存 Key，本次运行仍保留当前 Key。

升级前保存在系统凭据库中的 Key **不会自动读取、迁移或删除**，首次升级后需重新填写。打开面板时若本地库没有该服务的 Key，会显示非阻塞提示；不要求鉴权的服务仍可留空使用。读取失败与“未保存”会分别提示：读取失败时先重试读取或明确重新填写，不会默默发送空 Key。只修改模型或其他偏好会等待正在恢复的 Key，不会用尚未恢复的空输入覆盖它。明确清空 Key 并保存，或点击删除按钮，才删除对应的应用本地条目；删除失败不会显示成功。

密钥文件位于应用配置目录的 `ai-secrets/`：`credentials.enc.json` 保存加密条目，`installation.key` 保存本机自动解锁材料，`vault.lock` 用于文件锁。每次加密使用新的随机 nonce。此方式保护静态保存的条目；**同时取得加密库与本机解密材料的人仍可恢复 Key**，不等同于系统钥匙串或用户主密码保护。Unix/macOS/Linux 上目录和文件权限为 0700/0600，并校验文件所有者及链接；Windows 使用用户应用数据目录继承的 ACL，另拒绝重解析点和非普通文件并使用独占文件句柄，未额外设置专用 ACL。备份这些应用文件时也应保护解密材料。删除单个 Key 不删除解密材料、锁文件或其他服务的条目。

## 发送问题与终端上下文

默认直接输入问题时，只发送当前对话。助手不会自动读取终端、自动附加命令历史或后台采集输出。另行启用[长期记忆](AI_MEMORY.md)和自动检索后，还会查询该机器及允许的全局记忆，将命中片段作为带来源的历史参考发送给模型；Embedding 服务与聊天服务分别配置。

需要解释选中的文本或最近输出时，使用相应的附加按钮。附加内容先显示在预览中，可以查看或移除，点击发送后才会进入本次请求。发送前应确认预览中没有不希望提供给模型服务的内容。

回答会逐步显示。点击停止可取消当前请求；取消后的迟到片段不会进入下一轮回答。新建对话会停止生成，并清空对话、输入草稿和待发送上下文。关闭面板也会停止当前生成，已经显示的对话保留在内存中。

最近输出最多附加 80 行、16000 字符。选区预览的移除按钮位于输入区顶部，长内容不会把它挤到末尾。停止或失败的聊天回复不会作为下一轮上下文；运维中实际执行过的命令和结果可作为后续任务的参考，未执行的命令不视为已执行。切换服务地址或模型后保存配置，会清空旧对话；更换地址会清空密钥输入，避免把旧服务密钥意外发给另一个服务。

## 上下文占用与压缩

输入区上方显示当前上下文的估算 token 数、模型容量和占用比例。配置中的容量应填写模型实际支持的窗口；这里的计数按文字估算，不能当作服务端分词或账单用量。

“压缩上下文”会调用当前模型，将较早的对话或执行记录概括为事实摘要，保留近期完整回合；运维模式保留原始任务与完整工具调用/结果组。单个近期记录过大时会把整组纳入摘要，避免拆散工具配对。默认接近容量时自动压缩，也可关闭自动压缩并手动操作。压缩会把待摘要记录发送到同一个配置端点，不会自动读取其他终端。

界面中的原对话和执行记录保留，后续请求使用摘要。摘要失败或用户取消时不替换原上下文，也不会静默丢掉旧记录继续执行。摘要只是参考数据，不增加执行授权。开始新对话会清空上下文和压缩次数。此流程参考 [OpenClaw 的上下文压缩机制](https://docs.openclaw.ai/concepts/compaction)。

## 长期记忆

助手顶部「长期记忆」打开管理页，支持当前机器与全局范围、Markdown 原文编辑、来源检索、冲突保护及删除备份。首次使用需独立填写 Embedding 地址、模型和可选 Key，再明确启用；默认关闭记忆。已勾选的「自动检索」和「包含全局」只有启用后才会自动外发检索请求。接口异常会展示关键词降级，不能将其当成向量成功。

回答上的「保存为记忆」只预填可编辑草稿，点击「保存记忆」才写入，且绑定产生回复的机器。新建对话不删除长期记忆。压缩前自动整理事实并追加机器日记是另一个默认关闭的开关；混有其他机器或归属不明的历史会跳过整理。配置、存储格式、确认边界和测试范围见[长期记忆说明](AI_MEMORY.md)。

## 命令建议

回答中的代码块可以复制。符合条件的单行命令可以插入当前终端，供手动检查后继续编辑：

- 插入只面向当前活动且已连接的终端，不向其他分屏或同步输入组广播。
- 插入不发送回车，不自动执行命令。
- 多行或包含控制字符的内容不能直接插入。
- 只有 Shell/终端语言标记或未指定语言的单行代码提供插入按钮，其他语言仍可复制。
- 终端断开或关闭后不能向其插入命令；重新连接后再操作。

## 数据保存范围

本机普通配置仅包含端点、模型、宽度、上下文容量、自动压缩、逐步确认、记忆检索及是否记住密钥等偏好。API Key 独立存入应用本地加密库，Embedding 与聊天使用不同命名空间；问题、回答、摘要及附加的终端上下文不写入普通配置，加密库和本机解密材料也不随机器的 Gist 同步上传。普通聊天仅在当前进程内存中保留。运维模式另有本机持久化运行日志，保存任务、工具调用、结果与批准事件，支持查看和显式恢复，不随 Gist 同步；明文内容及容量边界见 [AI 运行框架与恢复](AI_HARNESS.md)。用户明确保存、确认 Agent 写入或另行启用压缩前整理的记忆，会以本机 Markdown 及 SQLite 派生索引持久保存；这些文件是明文，不适合存放凭据。

用户点击发送后，问题、当前对话与主动附加的内容会发往所配置的模型服务；启用记忆后还可能包含检索来源片段，启用整理后会发送待提炼历史。问题和待索引片段也可能发送到独立配置的 Embedding 服务。内容处理由对应服务负责。关闭面板与退出软件是不同操作：需要清空当前对话时使用新建对话；需要删除长期记忆时使用记忆管理页。

网络请求由原生后端发送，因此不依赖浏览器 CORS 配置。AI 不继承 GitHub 专用代理，不跟随接口重定向；如服务返回跳转，请填写最终接口地址。对话模式使用文本 Chat Completions；运维模式使用同一接口的原生 function/tool calling。不包含图像或原生 Anthropic/Responses 协议。

接口格式参考：[创建 Chat Completion](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[流式增量格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events)。兼容性仍取决于具体服务，本项目测试使用本地受控服务，不代表已连接所有厂商模型。

## Markdown 与流式显示

AI 回复支持标题、列表、引用、表格、链接、行内代码和代码块。代码可以复制；仅完整回复中闭合的 Shell 单行代码块提供“插入终端”，不会添加回车。运维助手按模型分析、命令、实际输出、最终结论依次显示，流式文字不构成工具执行授权。停止或失败时保留已有内容并标注状态，后续请求不使用未完成回复。

点击输入框上方“Markdown”选择 UTF-8 `.md` 或 `.markdown` 文件，文件须非空且不超过 64 KiB。可先查看排版、移除，再点击发送；文件内容按不可信参考数据传入，不自动执行其中命令。文件读取期间新建对话、关闭面板或切换机器会取消附加。纯文本原文用于上下文，排版不会修改文件。

长期记忆管理保留 Markdown 原文编辑与保存，同时预览已保存原文和未保存草稿；记忆引用也可排版显示。原始 HTML 按文本显示，远程图片只显示说明和手动查看链接。

验证：`npm run test:ai-markdown`、`npm run test:ai-agent-stream`、`npm run test:ai-markdown-ui`，另有记忆 UI 和终端输入回归。测试使用真实前端模块及受控本地传输，不访问用户模型账号。
