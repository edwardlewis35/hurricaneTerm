# 连接、分屏与选择复制

标签旁的连接箭头按「最近使用的机器」和「已保存的机器」分组。保存但从未连接过的机器也在列表中；同一个保存条目只出现一次。最近组最多显示10项，其余保存条目仍可找到。第二行功能栏的分屏按钮提供向右、向下分屏与恢复独立标签；再次点击按钮、按Esc或点击外部可收起菜单，原分屏快捷键继续可用。

连接失败会显示持续保留的详情窗口，包含连接名称、协议、目标、失败阶段和底层原因。可复制详情、关闭窗口或重试；已有窗格重试时保留原标签及滚动输出。SSH分别报告地址解析、TCP、代理/跳板、握手、认证、主机密钥、PTY和Shell失败；主动关闭连接不显示失败窗口。Telnet、TCP和串口打开时的同步错误也会显示。成功连接不再弹出提示打开SFTP的消息，文件管理仍可从功能栏打开。

错误信息会过滤当前连接密码、代理凭据、明显的令牌字段及私钥内容，并移除终端控制序列。目标地址、用户名、路径和系统错误仍会保留，以便排查；共享错误详情前可再次检查实际文本。错误回显不进入自动发送触发器。已关闭窗格或旧连接的迟到错误不会覆盖新连接。

终端选中非空文字会自动复制。拖动中合并选择更新，鼠标松开时立即提交当前选区；清空选择、关闭终端或关闭「选中自动复制」后，不会把待处理的旧选区重新写入。选择本身不会执行命令或广播输入。可在设置→终端关闭此行为，仍可使用Ctrl/Cmd+Shift+C复制。

桌面复制使用[官方Tauri剪贴板插件](https://v2.tauri.app/plugin/clipboard/)，只授予写入文本权限；普通浏览器预览使用浏览器剪贴板并提供兼容回退。复制失败会提示，连续自动复制失败不会反复刷屏，后续成功可恢复正常状态。Linux Wayland下的原生剪贴板可用性取决于桌面协议与XWayland环境，实际客户端应以复制结果为准。
